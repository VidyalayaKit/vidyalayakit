# Contributing to Vidyalaya Kit

Thanks for your interest in contributing! Vidyalaya Kit runs on a **two-track model** — read this before you start, so you know which track fits you.

This project is licensed under the **Dhanu Sir Community License (DSCL)** — see [DSCL-LICENSE.md](./DSCL-LICENSE.md) — and sponsored by **Code To Earn Pvt. Ltd.** (see [README.md](./README.md)). Please read both before contributing, since they define what you can and can't do with this code.

---

## The Two Tracks

### 🟢 Track 1: Open Contributor (free, open to anyone)

Anyone can contribute code, documentation, translations, bug reports, or design improvements to this project — no license or fee required. This is how everyone starts, including future Dhanu Sir Tech Team members.

**What you can do as an Open Contributor:**
- Fix bugs, improve accessibility, add features to the free/core template
- Improve documentation, translations (especially Nepali ↔ English)
- Report issues, suggest UX improvements
- Join training sessions run by the Dhanu Sir Tech Team

**What you cannot do as an Open Contributor:**
- Sell deployment, customization, hosting, or support of Vidyalaya Kit to a third party (school, client, etc.) — see [DSCL-LICENSE.md](./DSCL-LICENSE.md), Section 2. This requires Dhanu Sir Tech Team member status (Track 2).

### 🔵 Track 2: Dhanu Sir Tech Team Member (for those who want to sell services)

If you want to legally offer paid Vidyalaya Kit deployment/customization/support services — to government or private schools — you need to become a **Dhanu Sir Tech Team Member** by signing the **Dhanu Sir Tech Team Member Agreement** with Code To Earn Pvt. Ltd.

**What Approved Members get:**
- Legal right to sell the Static and CMS tier services under the Vidyalaya Kit / Dhanu Sir Tech Team brand
- Access to premium/CMS-tier components not in the public repo
- Referral leads from Dhanu Sir Tech Team's own client pipeline
- A "Dhanu Sir Tech Team member" badge for marketing
- Ongoing mentorship and technical support from the core team

## Stages to Become a Dhanu Sir Tech Team Member

Becoming a Tech Team Member is a three stages process:

**Stage 1 — Significant Contribution**

Make a significant, verifiable contribution to the project. This is assessed and confirmed by Dhanu Sir or a project maintainer — not a fixed checklist, but a real judgment of whether your contribution shows genuine skill and reliability. Examples include (but aren't limited to):
- A meaningful feature, fix, or improvement merged into the codebase
- Sustained, high-quality documentation or translation work
- Mentoring/supporting other contributors in a visible, verifiable way

There's no fixed contribution count — quality and verification by Dhanu Sir or a maintainer matters more than volume.

**Stage 2 — Interview Process**

Once Stage 1 is verified, you go through an interview with Dhanu Sir or a project maintainer to confirm eligibility for the **Dhanu Sir Tech Team**. This interview covers your technical understanding, communication skills, and fit with the team's quality and community standards.

**Stage 3 — Fit for Community**

Beyond technical skill, we check whether you're a genuine fit for the community itself — through volunteering, active participation in community events, and community outreach.

This isn't a one-time check but an ongoing pattern of involvement, such as:
- Volunteering time to help other students or contributors
- Actively participating in Dhanu Sir Tech Team events, sessions, or discussions
- Contributing to community outreach (e.g., helping onboard schools, spreading the campaign, supporting fellow members)

This stage exists because Approved Developers represent the community publicly — technical skill alone isn't enough if it isn't paired with genuine investment in the community's purpose (training students, empowering schools).

Passing all three stages makes you eligible to sign the **Dhanu Sir Tech Team Member Agreement**, at which point you officially become a **Dhanu Sir Tech Team Member**.

> There is no fixed "buy the license" shortcut — this path exists to make sure Approved Developers can actually deliver quality work, since they'll be representing the Dhanu Sir Tech Team name and Code To Earn Pvt. Ltd.

## How to Contribute Code (Track 1)

1. **Fork** the repository and clone your fork
2. Create a branch: `git checkout -b fix/short-description` or `feature/short-description`
3. Make your changes, following the existing code style
4. Test locally before submitting
5. Open a Pull Request against `main` with:
   - A clear title and description of what changed and why
   - Screenshots for any visual changes
   - Reference to the related issue, if any
6. A maintainer will review and may request changes before merging

### Branch naming
- `fix/...` — bug fixes
- `feature/...` — new features
- `docs/...` — documentation only
- `design/...` — UI/UX only

### Code style
- Keep templates modular and reusable — avoid hardcoding school-specific content
- Comment non-obvious logic
- Match existing indentation/formatting in the file you're editing

## Reporting Issues

Use GitHub Issues. Include:
- What you expected vs. what happened
- Steps to reproduce (if a bug)
- Screenshots where relevant

## Code of Conduct

- Be respectful — this project trains students of all skill levels; assume good faith
- No harassment, discrimination, or gatekeeping of beginners
- Give constructive, specific feedback on PRs
- Credit others' work honestly

## Applying to Become a Dhanu Sir Tech Team Member

Once you believe you've met Stage 1 (significant contribution), reach out through [contact/application link] or message the Dhanu Sir Tech Team directly to request Stage 2 (interview). Include:
- Links to your merged contributions or portfolio
- Your availability and areas of interest (design, backend, CMS, training, etc.)
- Which region/tier of schools you're most interested in serving
